# 曜米數學教室 (Yaomi Math Class)

這是一個為國小學生設計的數學教學資源導覽網頁。採用可愛的粉嫩馬卡龍配色，提供低、中、高年級的精選教材連結。

## 🌐 線上預覽
您可以透過以下網址訪問網頁：
[https://seasu.github.io/YaomiMathClass/](https://seasu.github.io/YaomiMathClass/)

## 📖 教材內容
- **低年級**：適合一、二年級的基礎數學連結。
- **中年級**：適合三、四年級的進階數學連結。
- **高年級**：適合五、六年級的挑戰數學連結。

## 🛠️ 技術使用
- HTML5
- CSS3 (Vanilla CSS)
- Google Fonts (Noto Sans TC)
